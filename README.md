# CS 1.6 MOTD Builder

Візуальний конструктор самодостатніх HTML MOTD-сторінок для Counter-Strike 1.6. Застосунок працює у браузері, зберігає конфігурацію в LocalStorage та не потребує backend.

## Локальний запуск

Потрібен Node.js 20 або новіший.

```sh
npm install
npm run dev
```

Збірка для публікації: `npm run build`. Перегляд зібраної версії: `npm run preview`.

## Налаштування здібностей

Демо здібності містяться у `src/data/abilities.js`. Замініть назву, короткий опис, іконку та початковий стан на параметри вашого сервера. Конфігуратор не задає і не реалізує ігрову механіку.

## Cloudinary

Завантаження вмикається у секції «Cloudinary / налаштування»:

1. Створіть Cloudinary cloud та unsigned upload preset у панелі Cloudinary.
2. Вкажіть Cloud name і назву Upload preset у застосунку.
3. Оберіть файл (JPG, PNG або WEBP, до 3 MB), потім натисніть «Завантажити».

Використовується лише Unsigned Upload API. API key та API secret не потрібні й не повинні додаватися у frontend. Cloudinary налаштування зберігаються локально в браузері; якщо не налаштовувати сервіс, можна вставити HTTPS URL зображення.

## GitHub Pages

1. Створіть GitHub-репозиторій і запуште проєкт у гілку `main`.
2. У репозиторії відкрийте **Settings → Pages** і виберіть **GitHub Actions** як джерело публікації.
3. Workflow `.github/workflows/deploy.yml` автоматично збере та опублікує сайт після push у `main`.

Vite бере назву репозиторію з `GITHUB_REPOSITORY` у GitHub Actions і формує відповідний `base` для GitHub Pages. Для локального запуску використовується `/`.

## MOTD та сумісність

Експорт генерує HTML без JavaScript, зовнішніх шрифтів і CSS-фреймворків; текст користувача екранується. Для зображень у файлі використовується HTTPS URL. Стандартний лічильник — 1536 символів; його можна змінити у налаштуваннях. Різні збірки CS 1.6 можуть мати власні обмеження MOTD, тому перевірте експорт на цільовому сервері.
